# 产品目标

Roomwave 是以虚拟人物为核心、由多个主题房间组成、支持持续互动和长期状态的 Web 应用。

用户在不同主题房间中活动；人物保持身份与外观连续；互动带来人物反馈和进度。增加房间、角色或动作时，应能够复用已有产品与运行时能力。

## 三个系统

- **Roomwave 产品**：房间导航、玩法、礼物、成长、外观、Solo/Together 和用户状态。
- **Spine Runtime**：人物加载、有限动作、对话编排适配、声音、中断和恢复。
- **Spine Manager**：角色与动作资源的检查、制作、打包、验证及候选推广。

AIRI 和 Rigby2D 为独立上游子项目；共用资源归入 resources。

## 当前阶段

先完成一条稳定的用户旅程：进入房间、触发互动、看到人物反馈、切房返回、按规则恢复状态。

c010 是人物接入样本。现有主题房间是产品回归基线。人物演出页先验证有限动作、回答和声音的生命周期，再按具体房间需求接入。

完成需要实际运行证据：资源可以加载，动作可以完成或中断并回待机，规定的状态可以恢复。功能测试与视觉接受分别记录。

## 工作边界

- 目录整理不扩张产品功能。
- 有实际复用后再抽象；不为未来可能性建立通用平台。
- 外部输入在模块入口校验，内部不重复检查同一条件。
- 保持原始资源与派生输出的来源清楚。
- 候选内容的制作、接入和正式发布分别判断。
