# 当前状态

更新日期：2026-11-05。

## 目录基线

产品前后端集中在 roomwave，人物运行时集中在 spine_runtime，资源生产归 spine_manager，共用素材与索引集中在 resources。AIRI 和 Rigby2D 是根目录的独立上游子项目。

旧 src 结构、重复页面、共享推流实验、退役审计页面和临时探针不再属于开发入口。仍被 c010 产品房间使用的 Canvas 实现保留在运行时模块。

## 产品

已有 Gaming、Hangout、Baking、Fitness、Fortunes、Karaoke。Solo 与 Together 共用 HTML 装配，房间业务模型供浏览器和后台复用。

Together 通过 HTTP 同步部分房间的命令与 checkpoint；c010 保持本地演出。Solo 衣柜保存到后台文件；共享房间和共享衣柜当前只存在内存。

## 人物运行时

AIRI / c010 单页演出支持人物加载、有限反应、固定脚本文字演练、中断、暂停恢复、固定 WAV 播放与导出的擦脸动画。真实 LLM、TTS、房间接入和远端观看均未接通。

旧 Canvas 路径保留 Character Pack 加载、动作调度、锚点和轨迹，用于当前产品 c010 互动。完整通用人物平台不是本轮整理内容。

## 资源生产

2026-11-05 复审更正：0.4.0 的视觉通过已撤销，当前状态为**表演需要重做**。掌面朝向不符合目标擦眼姿势；前臂抬到身前时，上臂被躯干遮掉，肩到肘的连接没有成立。此前将两者降为“视角限制/正常遮挡”的判断错误。0.4.0 暂保留在本地预览用于复现；导出和功能测试仍通过，但不构成视觉接受。

当前样本是 `c010_00@0.4.0`，批次 `c010-foam-wipe-v2-20261105`。擦脸使用 Rigby2D 派生工作文件中的 `foam_wipe`，时长 3.6 秒，保留原十个动画；已接入本地产品和 AIRI 预览，人物包仍是候选。前一版本保存在本批次 `rollback/c010_00/`。

新版制作了弯指轻拭的手形、独立腕指曲线、肩肘和头眼反应，以及少量发束/领带随动；补绘圆肩上臂纹理，袖片使用多骨权重与屈肘校正。逐帧检查修正了抬手/收手时的手腕过折，以及上臂袖片切换到前景的跳变。动作由生产资源表达，运行时没有另拼骨骼动作。

AIRI 和产品 Canvas 都读取真实导出动画与四个事件，擦脸期间不使用旧的生成骨骼变换或运行时 IK。泡沫在 `FoamCleared`（2.15 秒）清除，动画在 `FoamComplete`（3.6 秒）结束。水与风保留原配方路径。

Canvas 在加载选定皮肤后计算实际几何范围，避免依赖空的导出尺寸而缩放失效。0.4.0 已完成同 hash 的导出回读、双入口功能回归、AIRI 连续录制及有序帧检查，两套皮肤另有高清静态采样。这些证据中的掌向与上臂缺失问题被漏判，视觉验收失败。Canvas 仍有三角片抗锯齿细缝，画质不等同于 AIRI/WebGL。

正式发布仍受来源许可、待确认锚点、未支持动作与 runtime patch 等现有条件限制。目录迁移不改变这些接受标准。
