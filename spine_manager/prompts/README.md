# Prompt Versions

Prompt 是 Codex 主代理委派子代理时引用的版本化角色说明，不是项目内自动调用模型的配置。主代理负责选择 Prompt、传入证据包、回收结果和决定是否采用建议。

Prompt 必须按版本保存，并绑定运行结果。

每次修改 Prompt 都需要记录：

- 修改原因；
- 目标失败类型；
- 使用的回归案例；
- 修改前后的结果；
- 是否产生新回归；
- 保留或回滚的结论。

Prompt 只负责事实提取、假设、计划、动作规格和失败归因。它不能替代 Spine 工具，也不能自行宣布通过。独立审查 Prompt 不得包含执行者自评或其他审查结论。
