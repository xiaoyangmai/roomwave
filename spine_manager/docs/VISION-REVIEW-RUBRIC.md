# 大模型观感评估与四道门

## 作用

像素和几何指标回答“有没有越界、有没有变形、有没有闪烁”；视觉模型回答“人看起来是否像一个合理的动作”。两者必须并列，不能互相替代。

视觉模型可以输入多张关键帧、原始参考图、动作说明和带标记的调试图。视觉输入支持图像描述、物体、形状、颜色和纹理分析，但模型在精确空间定位和计数上仍可能出错，所以它负责 G4 观感门和 G2/G3 的补充判断，不负责替代确定性硬检查。[Images and vision](https://developers.openai.com/api/docs/guides/images-vision)

## 四道完成门

四道门必须分别记录结果，不能用一个总分隐藏某一层失败：

| 门 | 主要问题 | 通过条件 |
|---|---|---|
| G1 确定性运行和语义 | 能否加载、路由、响应按钮、正确执行语义动作？ | 版本、加载、控制台、动作存在、共享目标和回 idle 均无硬失败 |
| G2 动作与时间 | 动作是否自然、可读、接触可信、打断稳定？ | 准备、接触、停留、回收和恢复都有可解释的关键帧与轨迹 |
| G3 结构、服装和材质 | 衣服、背带、枪、头发、关节、遮挡和身份是否稳定？ | 无明显穿插、拉伸、断裂、闪烁、身份漂移或锚点串动 |
| G4 人类视觉观感 | 人是否会认为这是完成度足够、符合目标风格的动作？ | 多角色复核无重大分歧，且没有未解决的 `UNKNOWN` |

G1 到 G3 的硬失败不能被 G4 的审美高分抵消。G4 的低置信度或评审分歧也不能被平均分掩盖。

## 给视觉评估 Agent 的输入

每次只提供小而明确的证据包：

- 目标动作说明和接触点说明。
- `before.png`、`after.png`、动作开始/接触/结束关键帧。
- 一张带颜色标记的调试图：真实手、手部目标、背带目标、脸部目标、泡沫锚点。
- 约束摘要：哪些骨骼和插槽应该动，哪些必须保持不动。
- 硬指标摘要，但不提供生成 Agent 的解释。

不要把整份百万行审计 JSON 或全部候选图塞给模型。先让确定性工具筛掉明显错误，再让视觉模型看少量可比较证据。

## 评分维度

每项 1 到 5 分，并要求一句具体证据和一个可执行整改建议：

| 维度 | 评估问题 |
|---|---|
| action_readability | 人能否一眼看懂角色在做什么？手的运动意图是否清楚？ |
| hand_contact_plausibility | 手、脸、泡沫和道具是否真的接触，而不是擦边或悬空？ |
| identity_and_costume_consistency | 发型、服装、装备、颜色和角色身份是否保持？ |
| occlusion_and_layer_order | 手、袖口、背带、枪和头发的前后关系是否合理？ |
| anatomy_and_artifact_risk | 是否出现多余手指、融合、断裂、拉伸或奇怪高光？ |
| overall_human_view | 如果只看关键帧，人是否会认为这是一个完成度足够的动作？ |
| semantic_intent | 不看按钮文字时，人能否理解角色正在做预期的事？ |
| motion_naturalness | 准备、加速、接触、停留、回收和重心变化是否自然？ |
| temporal_coherence | 相邻帧是否稳定，是否有跳变、闪烁或残留轨道？ |
| garment_structure | 衣服、背带、枪械和头发是否按结构合理跟随？ |
| anchor_plausibility | 效果是否跟随可信的语义位置，而不是偶然骨骼？ |
| staging_aesthetic | 剪影、构图、视觉重点、表情和节奏是否符合目标风格？ |
| interaction_clarity | 用户是否能清楚理解按钮、动作和效果之间的因果关系？ |

评分还要分四层，避免模型只评“漂亮”：

- **全局层**：身份、轮廓、服装和装备是否一致。
- **局部层**：手指、袖口、背带穿插、透明边缘和局部伪影。
- **时间层**：手部轨迹、接触停留、动作回收和帧间闪烁。
- **语义层**：手是否命中脸/泡沫，背带是否独立，道具是否仍在正确挂点。

## 防止大模型“看起来不错”

1. 视觉 Agent 不得只看单张最漂亮的图，必须看动作关键帧序列。
2. 必须同时看正常图、调试标记图和前后对比图。
3. 必须引用 frame、time 和具体区域，不能只说“整体不错”。
4. 至少由动画、技术美术、视觉导演、产品和对抗五个角色独立评分，分歧超过 1 分时进入复评。
5. 视觉评分不能覆盖 mask 外像素变化、alpha 污染、崩溃和版本错配等硬失败。
6. 模型给出的整改建议必须翻译成一个可执行实验，例如“关闭 string_2 混合后重放”，不能直接变成无约束的全图重绘。

如果任一角色在任一维度相差超过 1 分、置信度低于 0.8，存在互相矛盾的结论或未解决的 `UNKNOWN`，就增加复评或重新渲染；仍不能达成一致时标记 `blocked_visual_uncertainty`，不自动合并。

## 多角色审查职责

- **动画师**：看动作意图、节奏、重心、接触、停留、回收和打断。
- **技术美术**：看骨骼、约束、权重、衣服、背带、枪械、头发、网格和遮挡。
- **视觉导演**：看剪影、构图、角色身份、材质、颜色、表情和整体气质。
- **产品审查者**：看按钮反馈、直播节奏、效果因果和用户是否理解动作。
- **对抗审查者**：专门寻找极限姿势、重复点击、快速打断、窄屏和低帧率失败。
- **裁决者**：只读证据包和独立评审，不读生成 Agent 的解释；负责合并分歧并决定 `pass`、`review`、`fail` 或 `blocked_visual_uncertainty`。

## 让评分变得越来越可靠

第一批 c010 样本不要直接拿阈值决定发布。先保存一组“可接受”和“明显不可接受”的关键帧，由规则检查和视觉 Agent 同时评分。比较两者的误报和漏报：

- 规则通过、视觉拒绝：通常是动作意图、遮挡或风格问题。
- 规则拒绝、视觉通过：通常是边缘污染、越界或模型没看清细节。
- 两者都分歧：增加证据、提高图像 detail，或将问题标记为不确定。

每完成一轮，加入经过验证的样本，重新估计软阈值。硬阈值只允许在证明误报后调整；不能为了让某个候选通过而临时放宽。

没有人工标注时，可以先用原始 `idle` 和已通过的关键帧作为正样本，再自动注入已知坏样本：mask 外泄、颜色漂移、背带跟手、权重拉伸和时间跳帧。对每个失败标签分别校准，优先降低误接收；阈值变化写入 calibration 文件，不能在当前轮次临时改变。

只对“最接近阈值、视觉评分分歧最大、机器指标与人类观感冲突”的样本生成新候选和新姿势。这种主动学习比无目的地增加候选数量更有效。
