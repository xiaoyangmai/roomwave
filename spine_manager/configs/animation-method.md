# 动作生产方法与本轮证据索引

2026-11-07 整理。用于 Roomwave / c010；通用制作和检查方法分别维护在 `$animation-authoring` 与 `$animation-inspection`，不在仓库再复制一整套 skill。先从 `AGENTS.md` 选择技能，再按遇到的问题读取本页相关小节。历史记录和本机路径使用前重新核实。

## 本轮值得复用的方法

- **先借用成立的部分，再验证变化。** 从原 `action` 复用肩肘袖型和身体节奏，使研究更快进入整身可观察状态；原来的手形硬切、握带和回程仍需验证，不整段继承质量结论。
- **制作单元是姿势之间的过渡。** 两端图像相似或骨骼可动都不够。用小样检查同一只手的腕口、掌根、指根、掌背视角及遮挡底图，先解决必经的松握和转面。
- **每轮回答一个可证伪的问题。** 如“原分指能否代替握拳起点”“腕袖拉伸是否消失”。保留对照与条件；若主轮廓没有改善，换姿势/素材假设，不继续堆局部补丁。
- **把产品与诊断证据配对。** 正常播放确认行为，再用同状态的去特效、部件隔离或高清 seek 定位原因。诊断更清楚不代表默认画面已经可读。
- **技术、视觉与偏好分开记录。** 工具成功、功能通过、可见动作、用户观感各有价值。用户本轮认为整体效果不错，可据此保留方向、聚焦打磨；不据此虚构未观察的手指、入口或接触细节。

## 遇到 Grok 超时或输出不适用

按 `AGENTS.md` 使用 Grok Build，工作与输出目录留在 MCP 工作区；原始返回、提示词、参考指纹、会话日志与图片按来源复制到生产批次。新任务不直接覆盖已审候选。

先区分请求等待、内部生成、最终返回和媒体收集。超时不证明没有生成图片；检查本次会话日志和中间产物，把试稿与最终输出分开。没有证据时不把原因归结为网络或下载。

本机桥的图片上限由 180 秒调为 600 秒后，新进程的一次请求用 291.6 秒完成；既有驻留进程仍需重新连接才加载源码变更。这是本次验证的配置，不是通用超时建议。修改后要验证实际运行实例返回的配置，不能只确认磁盘文件已改。

同轮三姿势请求仍在 600 秒超时；单张半松握虽成功返回，图像却张开过大且不能逐指对应。遇到此类问题应缩小要验证的姿势差异，先验素材再绑定；不无限加时或无变化重试，也不把换工具当成默认修复。不得通过改名或换路径重试此前被拒绝的同一编辑请求。

## 遇到 Spine 工程读取与版本问题

原件保留，建立指纹相同的副本，用实际工具读取并导出；不要修改版本字符串冒充转换。区分便携启动包装器参数和 Spine 参数，分别检查启动、读取和导出的结果。

本机 4.3.26 包装器转发形式为 `SpinePortable.exe --wait -- ...`，实际读取原 4.0.47 工程成功。可复现命令、工具路径和结果见 [Spine 恢复记录](../artifacts/runs/c010-spine-recovery-20261106/README.md)。这是本机包装器语法，不套用于其他安装。

对比导出时分开看骨骼/附件/约束与动画。静态结构相同不证明动画等效；本次导出增加了部分静态通道。PNG 存在、图集收录、骨架引用和可用绑定分别核实：本次没有恢复额外手指或袖片绑定，不推断编辑器内绝无其他信息。

## 判断手形与绑定缺口

先读 [分片与握拳的同姿势对照](../artifacts/runs/c010-split-hand-prior-pose-20261106/README.md)。其中原拳、原分片、完整拳覆盖、局部拓扑裁切是四个临时 WebGL 诊断，不是四个可交付动画：独立指骨存在，但当前拼法分别造成红掌露出、重复手指或接缝。可用来提出补绘/拓扑需求，不能据此排除其他姿势路线。

涉及图片到骨架映射时参考 [非对称点与二维反射复核](../artifacts/runs/c010-right-hand-unmirrored-20261106/README.md)；涉及三维代理时参考 [代理范围与未拟合项](../artifacts/runs/c010-right-hand-face-probe-20261106/README.md)。二维无反射、代理点碰到人工平面，都不是手性、指腹接触或整身人体运动合理性结论。

## 候选接入与检查

候选保留在独立批次，AIRI 测试/录像用 `ROOMWAVE_C010_ZIP` 指向候选 ZIP，Canvas 测试用 `ROOMWAVE_C010_PACK` 指向候选 pack。这样可验证研究版而不替换正式角色包或共享 ZIP；服务仍需按当前脚本准备。

`spine_runtime/tests/foam-review-timing.cjs` 从被测骨架读取四个 Foam 事件；`foam-review-anchor.cjs` 检查父链。换时长或换手后重新读取当前数据，并验证画面中的事件语义。原动作合法的 `HighlightFrame` 不应为满足旧测试被删掉。命令、当前严格事件先后条件、测试专用 1.8 秒样本与覆盖范围见 [采样工具记录](../artifacts/runs/c010-timing-test-20261106/README.md)；该样本只验证工具，不是成品。
